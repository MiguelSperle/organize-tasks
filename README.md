# Task Tracker

Uma aplicação web simples para organizar e acompanhar tarefas.

O objetivo deste projeto não é a aplicação em si, mas oferecer um sistema simples, previsível e independente para escrever, executar e aprimorar meus conhecimentos em Testes End-to-End (E2E) automatizados com Playwright.

> Divulgação sobre o uso de IA: este projeto foi criado com o auxílio de inteligência artificial. O código da aplicação foi produzido com a assistência do Claude, da Anthropic.
